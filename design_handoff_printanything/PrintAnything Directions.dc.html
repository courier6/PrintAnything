1PrintAnything — three directions, all states clickable

Each mockup is a 1120px desktop screen. Use the state tabs above each card to flip between Empty → Processing → Preview → Error; in Preview, click Print to see the color-mode reminder, and switch ink swatches (they really re-render). 1a is the brief's full-duotone idea — the whole UI re-inks with the swatch, hold-to-compare. 1b is a technical/blueprint take with a draggable split compare. 1c is a warm paper-and-serif take with side-by-side compare; only the preview re-inks.
